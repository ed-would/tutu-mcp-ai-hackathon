# Memory Bank

`docs/memory-bank` stores live operational context for the **Travel Tinder** hackathon project (Tutu MCP, 19–20 Aug 2026).

## Files

* `index.md` — live map of active files and key external refs.
* `current-state.md` — project status, what is done, open risks.
* `next-actions.md` — pre-freeze and pitch-day execution queue.
* `assumptions.md` — active product/tech assumptions for submission.
* `experiments.md` — design decisions tested and adopted during development.

## Triage rule

* Need it to keep work moving → `memory-bank`.
* Need it to explain why/how we decided → `docs/plans/product-travel-tinder.md` or the relevant `travel-tinder-exec-*.md` plan.
* No longer needed → `docs/plans/archive/`.
