## Cursor-first (within a Cursor project)

When the team standardises on **Cursor** as the primary agent IDE:

- **Cursor-first:** Prefer conventions Cursor loads automatically (`.cursor/rules`, `.cursor/skills`, `.cursor/agents`, `AGENTS.md`) so agents need less manual context each session.
- Treat [Cursor documentation](https://cursor.com/docs) as authoritative for feature names and file locations.
